Cookies em JavaScript

Cookies são pequenos arquivos de texto armazenados no navegador para persistir dados entre sessões. Em JS, você os manipula via `document.cookie`.

---

Criar / Definir um cookie

``javascript``
document.cookie = "nome=João";

// Com opções
document.cookie = "nome=João; expires=Fri, 31 Dec 2026 23:59:59 GMT; path=/";
```

Opções disponíveis:

| Opção | Descrição |
|-------|-----------|
| `expires` | Data de expiração (padrão: sessão) |
| `max-age` | Tempo em segundos até expirar |
| `path` | Caminho onde o cookie é válido |
| `domain` | Domínio onde é acessível |
| `secure` | Só enviado via HTTPS |
| `samesite` | Proteção contra CSRF (`Strict`, `Lax`, `None`) |

---

Ler cookies

``javascript``

console.log(document.cookie);
// "nome=João; tema=escuro; idioma=pt"

// Função para pegar um cookie específico
function getCookie(name) {
  const cookies = document.cookie.split("; ");
  const found = cookies.find(c => c.startsWith(name + "="));
  return found ? found.split("=")[1] : null;
}

getCookie("nome"); // "João"
```

---

Atualizar um cookie

Basta definir o mesmo nome com novo valor:

``javascript``

document.cookie = "nome=Maria; path=/";
```

---

Deletar um cookie

Define a data de expiração no passado:

``javascript``

document.cookie = "nome=; expires=Thu, 01 Jan 1970 00:00:00 GMT; path=/";
```

---

Exemplo prático completo

``javascript``

// Salvar preferência do usuário
function setCookie(name, value, days) {
  const expires = new Date();
  expires.setDate(expires.getDate() + days);
  document.cookie = `${name}=${value}; expires=${expires.toUTCString()}; path=/`;
}

function getCookie(name) {
  const match = document.cookie.match(new RegExp(`(^| )${name}=([^;]+)`));
  return match ? match[2] : null;
}

function deleteCookie(name) {
  document.cookie = `${name}=; expires=Thu, 01 Jan 1970 00:00:00 GMT; path=/`;
}

// Uso
setCookie("tema", "escuro", 30);  // dura 30 dias
getCookie("tema");                 // "escuro"
deleteCookie("tema");
```

---

⚠️ Pontos importantes

- Limite: 4KB por cookie e 20 cookies por domínio

- ``document.cookie`` não é um objeto — é uma string especial; cada atribuição "adiciona/atualiza", não substitui tudo

- Cookies ``HttpOnly`` (definidos pelo servidor) não são acessíveis via JS por segurança

- Para dados maiores, prefira ``localStorage`` ou ``sessionStorage``
