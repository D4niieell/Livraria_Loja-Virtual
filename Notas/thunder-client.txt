Thunder Client no VS Code para JavaScript

O Thunder Client é uma extensão leve para testar APIs REST diretamente no VS Code, funcionando de forma similar ao Postman.

Instalação

1. Abra o VS Code
2. Vá em "Extensions" (Ctrl + Shift + X)
3. Pesquise "Thunder Client"
4. Clique em "Install"

---

Interface Principal

Após instalar, um ícone de raio aparece na barra lateral. Ao clicar, você verá:

- New Request — cria uma nova requisição
- Collections — organiza requisições em grupos
- Env — gerencia variáveis de ambiente

---

Fazendo sua primeira requisição

1. Criando a requisição:
- Clique em New Request
- Escolha o método HTTP: `GET`, `POST`, `PUT`, `DELETE`, etc.
- Cole a URL da sua API

2. Exemplo com uma API pública:**
```
GET https://jsonplaceholder.typicode.com/posts/1
```
Clique em Send e veja o JSON de resposta.

---

Enviando dados (POST com JSON)

```
POST https://jsonplaceholder.typicode.com/posts
```

Na aba Body, selecione JSON e escreva:

```json
{
  "title": "Meu post",
  "body": "Conteúdo do post",
  "userId": 1
}
```

---

Headers

Na aba Headers, adicione cabeçalhos como:

| Key | Value |
---
| `Content-Type` | `application/json` |
---
| `Authorization` | `Bearer SEU_TOKEN` |

---

Variáveis de Ambiente

Útil para alternar entre dev e produção sem mudar URLs manualmente.

1. Vá em Env → Manage Env → Add
2. Crie um ambiente, ex: `Development`
3. Adicione variáveis:

| Key | Value |
---
| `baseUrl` | `http://localhost:3000` |
---
| `token` | `abc123` |

4. Use nas requisições com duplas chaves:
```
GET {{baseUrl}}/users
Authorization: Bearer {{token}}
```

---

Integrando com seu código JS

Após testar no Thunder Client, você replica a requisição no código:

```js
// Exemplo equivalente em fetch
const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer SEU_TOKEN"
  },
  body: JSON.stringify({
    title: "Meu post",
    body: "Conteúdo do post",
    userId: 1
  })
});

const data = await response.json();
console.log(data);
```

O Thunder Client até gera esse código automaticamente — clique em **{}** (Code Snippet) após a requisição.

---

Collections

Organize suas rotas em coleções por projeto:

- New Collection → ex: `Minha API`
- Salve requisições dentro dela
- Exporte como JSON para compartilhar com o time (`.thunder-collection.json`)

---

Dicas Rápidas

| Ação | Como fazer |
---
| Autenticação Basic | Aba Auth → Basic |
---
| Autenticação Bearer | Aba **Auth → Bearer |
---
| Query Params | Aba Query ou direto na URL com `?chave=valor` |
---
| Ver histórico | Menu Activity |
---
| Testar GraphQL | Selecione método GQL |

O Thunder Client é ideal para desenvolvedores JS que querem testar endpoints de APIs Node/Express sem sair do VS Code.
